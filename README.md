# ✅ TaskFlow Pro PWA

A smart, feature-rich task manager built as a **Progressive Web App** — installable on any device, works fully offline.

## ✨ Features

- ✅ Add tasks with **priority levels** — High, Medium, Low
- ✅ **Category tags** — Work, Personal, Shopping, Health
- ✅ **Progress bar** — live completion tracking
- ✅ **Stats panel** — total, done, remaining
- ✅ **Filter chips** — All, Active, Done, by priority
- ✅ **localStorage** — data persists across sessions
- ✅ Clear completed tasks in one tap
- ✅ Smooth animations & micro-interactions
- ✅ Installable on Android & iOS (PWA)
- ✅ Works fully offline
- ✅ Zero dependencies — pure HTML, CSS, JS

---

## 📱 Install on Phone

1. Open the [live link](https://MBSKmax.github.io/taskflow-pro-pwa) in Chrome
2. Tap **"Add to Home Screen"** or the install banner
3. Done — works like a native app!
